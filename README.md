# 🩺 Diabetic Retinopathy Prediction Using Machine Learning

## 📌 Project Overview

This project uses **Machine Learning** to predict diabetic retinopathy based on patient clinical information.

A trained **Support Vector Machine (SVM)** model is integrated into a **Streamlit web application**, allowing users to enter patient information and receive a prediction with the model's confidence.

The application uses the following patient features:

* Age
* Systolic Blood Pressure
* Diastolic Blood Pressure
* Cholesterol

## 🎯 Objectives

* Perform data analysis and preprocessing.
* Build a machine learning classification model.
* Apply feature scaling using a saved scaler.
* Save and reuse the trained SVM model.
* Develop an interactive Streamlit application.
* Generate predictions from user-provided clinical information.

## 🤖 Machine Learning Model

The project uses a **Support Vector Machine (SVM)** classification model.

The trained model is stored in:

```text
svm_retinopathy_model.pkl
```

The preprocessing scaler is stored in:

```text
scaler.pkl
```

The Streamlit application loads both saved artifacts and applies the same preprocessing before making predictions.

## 💻 Streamlit Application

The application provides an interactive interface where users can enter:

| Feature      | Description              |
| ------------ | ------------------------ |
| Age          | Patient age              |
| Systolic BP  | Systolic blood pressure  |
| Diastolic BP | Diastolic blood pressure |
| Cholesterol  | Cholesterol value        |

After clicking **Predict**, the application displays:

* Prediction result
* Prediction confidence
* Entered patient information

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/javeed10-19/diabetic-retinopathy-prediction.git
```

### 2. Open the Project Folder

```bash
cd diabetic-retinopathy-prediction
```

### 3. Create a Virtual Environment

For Windows:

```bash
python -m venv venv
```

Activate it:

```bash
venv\Scripts\activate
```

### 4. Install Required Libraries

```bash
pip install -r requirements.txt
```

### 5. Run the Streamlit Application

```bash
streamlit run app.py
```

The application will normally open at:

```text
http://localhost:8501
```
